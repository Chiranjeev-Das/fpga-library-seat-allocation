# FPGA-Based Library Seat Allocation System

## Overview
A hardware-driven seat allocation system implemented using FPGA-based digital logic. The system models 32 library seats organized into multiple banks and supports deterministic seat booking and release.

## Features
- 32-seat modeling using modular RTL design
- Debounced user input handling
- Priority-based seat suggestion logic
- Synchronous booking and release
- Real-time seat availability display using LEDs and seven-segment displays

## Implementation
Designed using Verilog HDL with emphasis on deterministic hardware behavior and modular RTL structure.

## Notes
This project was developed as an academic FPGA hardware design project.
